# 託すノート

社長と幹部が、答えるたびに問いが変わる診断と、短い学び、3分コーチングでマネジメント力を育てていくための試作です。

- 画面：https://kotam-san.github.io/takusu-note/
- 仕組みの図：https://kotam-san.github.io/takusu-note/how.html

## 何に困っているのか

中小企業の社長の多くは「任せたいのに、結局自分が決めてしまう」と感じています。

幹部の側は「何を任されているのか、どこまで自分で決めてよいのかが分からない」と感じています。

診断のツールは世の中にたくさんありますが、多くは1回答えて結果を見たら終わりです。

答えた後に何をすればよいのか、次の週に何が変わったのかは、どこにも残りません。

## 何ができるのか

はじめて使うときは、役職・直属の部下の数・今の立場の年数・業種を選び、「いま引っかかっていること」を書きます（会社名や人の名前は聞きません）。AIがそれを手がかりに、1回目の深掘りの6問と、推移を見る4問に添える例を作ります。AIが使えないときは、選んだ内容に合わせて用意した問いで始めます。

1回の流れは次の4つです。

1. **答える**：毎回同じ「推移を見る4問」と、毎回変わる「深掘りの6問」、それに「いま引っかかっていること」を書く
2. **AIの見立てと、今日の学び**：今の状態と、いちばん伸びしろのある軸についての短い教材、理解を確かめる問い
3. **3分コーチング**：AIの問いに答えると、言葉を受け止めたうえで今週の一歩を3つ提案し、本人が1つ選ぶ
4. **次の問いをつくる**：AIが、点数の低い軸・引っかかりの言葉・コーチングでの答え・前回の一歩をやれたか、の4つを手がかりに、次の回の深掘りの6問を作る。問いごとに「〜という答えを受けて」と理由を添える

回を重ねると、4つの軸の点数の推移と、これまでの一歩とやれた率が積み上がります。

社長も幹部も、ひとりでこっそり使えます。記録を誰かに見せる仕組みはありません。

4つの軸は次のとおりです。

| 軸 | 見ていること |
|---|---|
| A 任せる・任される | 仕事を任せ切れているか、任されたことを自分の判断で進められているか |
| B 社長がいなくても決まるか | 社長の不在時に、現場で判断が下されているか |
| C 言われる前に動くか | 問題が起きる前に、考えて動き、提案が出てくるか |
| D 数字と方向の共有 | 会社の数字と今後の方向が、社長と幹部の間で行き来しているか |

## 誰が最初に使うのか

作者は、中小企業の社長と幹部の育成を支えるコーチです。

クライアントの社長と幹部に、毎週のセッションの合間にこの試作を使ってもらい、その記録をセッションの入口に使います。

作者自身が毎週使う道具として磨いていきます。

## 数で見ること

中継（Worker）は、答えの中身を保存せず、回数だけを数えています（`/api/stats`）。

- 1周を終えた率（見立てを受けた回のうち、今週の一歩まで決めた割合）
- 2回目以降の回の割合（戻ってきて続けているか）
- 前回の一歩をやれた率

## 答えの扱い

- 答えと自由記述は、診断のために AI（Claude）へ送られます。中継は本文を保存せず、ログにも出しません
- はじめに選んだプロフィールも、答えと同じく AI へ送り、ブラウザの中にだけ残します
- 記録は、使っている人のブラウザの中（localStorage）にだけ残ります。「記録をすべて消す」で消せます
- 実名や取引先の名前は書かないよう、画面で案内しています

## 作り

```
docs/      画面（GitHub Pages）。index.html・app.js・core.js（計算）・profile.js（はじめに聞くこと）・questions.js（最初の問いと出し分け）・how.html（仕組みの図）
worker/    AI を呼ぶ中継（Cloudflare Worker）。鍵は Cloudflare の秘密の設定に置き、画面には出さない
tests/     記録の検証・推移の計算・プロフィールと1回目の問いのテスト
```

- AI：Claude（`claude-sonnet-5-5`）。決めた形（JSON）で受け取り、件数と選択肢の形を確かめてから画面に返します。安全上の理由で断られたときは、推奨の別モデルで自動的にやり直します
- 悪用への備え：IP ごとの回数制限、1日の全体上限、入力の長さの上限、出力の上限。呼び出し元（Origin）の確認はブラウザ向けの補助で、認証ではありません。最後の歯止めとして、API 側に月の利用上限を設定しています
- 自由記述に指示が書かれていても、AI はそれを指示として扱わず、相手の状態を知る材料としてだけ読みます

## 手元で動かす

```bash
cd worker
npm install
export ANTHROPIC_API_KEY=...        # 自分の鍵
export ALLOW_LOCALHOST=1
export CLOUDFLARE_INCLUDE_PROCESS_ENV=true
npx wrangler dev --port 8787
```

別のターミナルで画面を開きます。

```bash
python3 -m http.server 8768 --directory docs
```

http://localhost:8768 を開き、「回答例で試す」を押すと、架空の回答で1周を試せます。

## テスト

中継のテストは `@anthropic-ai/sdk` を読むので、先に `worker` で `npm install` を済ませます（AI は呼びません）。

```bash
node --test tests/core.test.mjs tests/worker.test.mjs tests/profile.test.mjs
```
